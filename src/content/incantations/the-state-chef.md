# The State

In the darkest kitchens of the cyberpunk underworld, the **State** is not merely coded; it is *cooked*. This profane recipe binds the principles of the Behavioral pattern into a physical manifestation of culinary dread. 

## Arcane Implementation

An abomination cannot remain static; it must evolve or adapt. The State pattern allows the core entity to don shifting skins. When the internal state changes (e.g., from "dormant" to "enraged"), the entity sheds its skin and equips a new State object. Its behavior completely changes—what once accepted commands now devours the invoker—as if the underlying class itself has morphed into a new horror.

- **Unstable Core**: The Context object.
- **Shifting Skins**: The concrete State implementations.
- **Trigger-Mechanism**: The event that causes the state transition.
