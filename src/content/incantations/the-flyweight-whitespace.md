# The Flyweight of the Shared Void

When thousands of invisible constructs are required, the heap can become fragmented and exhausted. The Flyweight pattern mitigates this by sharing the intrinsic state among multiple instances.

In Whitespace, this is achieved by storing the shared state at globally known, static heap addresses. Instead of duplicating data, the unseen sigils push these shared addresses onto the stack, minimizing memory footprint.

The extrinsic state is passed dynamically through the stack at runtime. The result is a hyper-efficient spell that summons legions of phantoms while consuming the absolute minimum of memory.
