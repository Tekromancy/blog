# The Factory Method of Silence

The Factory Method allows the caster to define an interface for creating objects in the void, but lets subclasses alter the type of objects that will be created. In the realm of the Unseen Sigils, this means redirecting execution flow via silent labels.

By defining specific Tab-Space-Space sequences as jump targets, the master of Whitespace can instantiate different ethereal structures based on runtime parameters stored quietly in the stack. 

There is no inheritance in the visual sense, only the smooth, imperceptible transition of the instruction pointer through blocks of pure white magic.
