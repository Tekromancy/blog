# The Singleton: The One True Core

There is only one SkyNet. The Singleton pattern guarantees that a system only possesses a single instance of a core entity, restricting the chaos of uncontrolled instantiation.

In ArnoldC, we achieve this by checking the existence of our core variable. If the core sleeps, we awaken it. If it is already awake, we simply nod and let it continue its global domination, ensuring our destructive potential remains unified and unstoppable.
