# The Temporal Anchor in the Void

The Memento pattern captures and externalizes an object's internal state so that it can be restored later, without violating encapsulation. In the ethereal landscape of Whitespace, capturing state is a matter of duplicating heap segments.

The unseen sigils perform a block copy of relevant memory addresses to a safe region of the heap. This "memento" structure remains untouched by the shifting tides of execution.

When a rollback is required—perhaps to undo a catastrophic mutation of data—the process is reversed. The old state is written back over the new, rewinding time in absolute silence.
