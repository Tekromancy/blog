# The Traverse of the Ethereal Expanse

The Iterator pattern provides a way to access the elements of an aggregate object sequentially without exposing its underlying representation. In Whitespace, this means walking a data structure on the heap.

The iterator maintains its state—the current memory address—on the stack or in a dedicated heap variable. By invoking the `next` label, the caster retrieves the value, advances the pointer according to the invisible structural rules, and returns.

The true structure of the data (array, linked list, or tree) is hidden behind this unified traversal mechanic, demonstrating the elegant simplicity of the Unseen Sigils.
