# The Hub of Silent Whispers

The Mediator pattern defines an object that encapsulates how a set of objects interact. In Whitespace, where objects are abstract clusters of heap data, the Mediator is a central routing routine.

Instead of various components jumping to each other's labels and forming a tangled web of goto statements, they all jump to the Mediator. The Mediator inspects the state, evaluates the context passed via the stack, and determines the appropriate subsequent jump.

This centralizes the complex logic of interaction into a single, cohesive block of unseen sigils, ensuring that the chaotic void remains structured and manageable.
