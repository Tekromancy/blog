---
title: Facade
description: Provide a unified, simple class to mask a complex set of underlying nested styles.
type: css
gofPattern: Facade
gofCategory: Structural
arcaneSchool: "Abjuration // Complexity Masking"
formula: |2
  /* Facade class masking a complex nested architecture */
  .grand-illusion {
    display: block;
    position: relative;
    overflow: hidden;
  }
  
  /* Underlying complexity managed internally */
  .grand-illusion > .mirror { filter: contrast(150%); }
  .grand-illusion > .smoke { opacity: 0.5; mix-blend-mode: multiply; }
  .grand-illusion > .lights { text-shadow: 0 0 10px yellow; position: absolute; }

The Facade pattern in CSS hides intricate sibling selectors and nested complexity behind a single straightforward parent class, allowing users to apply profound magical effects easily.
