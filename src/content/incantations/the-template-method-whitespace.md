# The Skeleton of the Unseen Ritual

The Template Method pattern defines the skeleton of an algorithm in an operation, deferring some steps to subclasses. In the esoteric arts of Whitespace, the skeleton is a central routine composed of sequential jumps to variable labels.

The base routine calls function pointers stored at predefined offsets from a base heap address. To create a "subclass" of this behavior, the caster populates those heap addresses with new, specialized labels before invoking the skeleton.

The overarching structure remains rigid and secure, enforced by the skeleton routine, while the detailed execution varies dynamically, guided by the silent manipulation of the void.
