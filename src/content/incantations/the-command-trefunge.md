The Command pattern allows tekromancers to treat spells as manipulable spatial packets. Rather than executing a Three-Dimensional Topology Ward immediately, the spell's parameters and execution path are placed (`p`) into a dense memory cube.

This Encapsulated Spell can be queued, passed to other layers, or triggered on a delay, granting immense flexibility in complex ritual timing sequences.
